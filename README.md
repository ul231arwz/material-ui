# Dashboard template

A simple dashboard layout with a sidebar, header, and content area.

## Features

- Responsive sidebar
- Header with search and profile menu
- Cards and charts for data visualization
- Accessibility-friendly markup

## Usage

1. Copy the files in this folder into your project.
2. Run `npm install` to install dependencies.
3. Replace the mock data in `DashboardContent.js` with your own.
4. Customize the theme in `theme.js` to match your brand.

## Accessibility notes

- Use semantic HTML (`<nav>`, `<main>`, `<header>`).
- All interactive elements have visible focus states.
- Color contrast meets WCAG AA standards.
